# EPS Печать

Программа для Windows: массовая печать EPS-файлов из zip-архивов с превью, выбором бумаги, масштаба, копий и листов.
Собирается на GitHub, ставится одним файлом и обновляется одной кнопкой.

## Скачать

**[EpsPrint-Setup.exe](https://github.com/nlbeglov/print/releases/latest/download/EpsPrint-Setup.exe)** — последняя версия.

1. Запустить. Windows может показать «Система Windows защитила ваш компьютер»: файл не подписан платным сертификатом. Нажать «Подробнее» → «Выполнить в любом случае».
2. Нажать «Установить» и разрешить запрос администратора (он нужен, чтобы закрыть программе доступ в интернет).
3. Готово: ярлык «EPS Печать» на рабочем столе.

Обновление: кнопка «Проверить обновления» в программе. Удаление: снова запустить установщик → «Удалить программу».

## Качество печати

PDF не используется. EPS (вектор) передаётся в Ghostscript, тот рисует его **сразу с разрешением принтера** с учётом масштаба
(у HP M132fn это 600×600 dpi) и **без сглаживания**. Готовая картинка кладётся на лист один к одному: 1 пиксель равен 1 точке принтера.
Отправить EPS «как есть» на M132fn нельзя: этот принтер не понимает PostScript.

## Принтеры для наклеек (Zebra)

Для Zebra (TLP 2844 и др.) выбирается **размер наклейки в рулоне** (например 40×30), а рисунок из EPS ставится на неё:
как в файле по центру или растянутым на всю наклейку. Печать идёт мимо драйвера Windows: принтер получает свои команды
(EPL или ZPL) с размером наклейки и зазором, поэтому не съезжает. Изображение рендерится в чистый чёрно-белый ровно
под головку (203/300 dpi). В «Ещё настройки» есть сдвиг, зазор, язык, калибровка (`xa` / `~JC`) и печать через драйвер.

## attributes.json

Из `attributes.json` («Честный знак») берутся сведения о товаре по GTIN. Файлы `…_<GTIN>_<n>.eps` подписываются
названием товара и номером кода, а в панели «О товаре» видны бренд, модель, цвет, ТН ВЭД, ИНН и число кодов.

## Из чего состоит

| Файл | Что делает | Интернет |
|---|---|---|
| `EpsPrint.exe` | основная программа | **нет**: сетевого кода нет, плюс блокировка брандмауэром |
| `gs\bin\gswin64c.exe` | Ghostscript 10.08 (встроен), запускается с `-dSAFER` | **нет**: блокировка брандмауэром |
| `Updater.exe` | запускается только кнопкой «Проверить обновления» | только HTTPS к `api.github.com` и `*.githubusercontent.com` |
| `EpsPrint-Setup.exe` | установка и удаление | нет |

Updater ставит пакет, только если версия в нём новее установленной и совпадает с тегом релиза, а внутри лишь
`EpsPrint.exe`, `Updater.exe`, `README.txt`. Если замена файлов не удалась, старые файлы возвращаются на место.
Обработка архивов: пути из zip не используются, есть лимиты по размеру и количеству файлов.

## Выпуск версии

Отправить тег версии, и GitHub Actions сам соберёт и опубликует релиз:
```
git tag -a v1.0.1 -m "Что нового: ..."
git push origin v1.0.1
```
Или вручную: **Actions → Release → Run workflow**. Секреты не нужны.

Каждый push проверяется сборкой (workflow **Build check**). Локально можно собрать на любом Windows 10/11 через `build.bat`.
